Invariants
Every card mutation goes through the same resolver → policy → one transaction → broadcast path whether it came from optimistic UI, offline replay or a direct API call. setViewing is the one exception: presence is not domain data.
The event layer never stores domain state — it only tells peers that Postgres changed. On the client, Apollo's cache owns domain data and MobX owns the sync engine; nothing lives in both.
